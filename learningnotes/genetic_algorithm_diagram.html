🧬 Genetic Algorithm Flow Diagram

🔄 Complete Algorithm Flow (population_size=5, num_of_generations=3)

This diagram is based on the following parameters:

  • population_size = 5: Each generation has 5 candidate formulas
  • num_of_generations = 3: Total of 3 generations of evolution
  • Uses asynchronous parallel LLM calls
  • Uses temperature-controlled Boltzmann selection

Key Points:

  • Initialization: Check if a constant function is sufficient (baseline test)
  • Generation 0: Generate initial population using LLM without parent context
  • Selection: Use Boltzmann distribution to select parents based on fitness scores
  • Elitism: Best individual from each generation is automatically preserved
  • Generation 1-N: Generate new individuals using selected parents as context
  • Parallel Processing: Use async calls to generate multiple individuals simultaneously
  • Final Result: All generations are returned, sorted by score within each generation
