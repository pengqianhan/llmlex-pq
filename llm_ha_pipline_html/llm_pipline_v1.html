Vision-LLM Island Evolution for Hybrid Automata

A visual walkthrough of island_ha_vlm.py: load Duffing traces, fit the forcing signal, template a seed automaton, and let a vision-enabled LLM plus island evolution deliver a validated hybrid model.

Context

From Plots to Verified Hybrid Automata

The script first calls load_duffing_npz() to down-sample the Duffing benchmark and to fit a compact sinusoidal forcing expression via fit_periodic_input. A two-mode seed from default_seed_json() is parameterised, and evolve_islands() orchestrates fitting, scoring, and LLM-guided structural edits across multiple populations.

Script Anatomy

Key Functions Inside island_ha_vlm.py

Data Handling

  • load_duffing_npz trims trajectories, applies stride, and derives the initial mode/state dictionary.
  • fit_periodic_input recovers a concise driving signal u(t) using FFT-based frequency estimation and least squares.

Template & Fitting

  • extract_param_template safeguards indices/exponents while exposing coefficients as {p_k}.
  • fit_params runs SciPy Nelder–Mead with the cost nchi_mean + 0.05 * rmse_mean and simulates through HybridAutomata.

LLM Interaction

  • image_to_base64 and vlm_propose package comparison plots and metrics for a vision model, returning schema-compliant JSON.
  • --use-vlm activates the OpenRouter client; otherwise evolution stays numeric.

Evolution

  • evaluate_candidate builds Candidate objects: fitted JSON, metrics, comparison plot.
  • evolve_islands manages elitism, jitter, migration, and writes best_automaton.json under build/islands_run/<timestamp>.
Pipeline

End-to-End Flow

1. Curate Duffing evidence

load_duffing_npz() samples data_duffing/test_data0.npz, applies stride/down-sampling, and fits u(t) ≈ cosine+sinusoid to seed the simulator.

2. Vision LLM proposal

When --use-vlm is set, vlm_propose() digests comparison plots + metrics to return a schema-valid automaton update.

3. Parameter templating

extract_param_template() replaces numeric literals with {p_k}, keeping indices/exponents intact for stable optimisation.

4. Hybrid simulation fitting

fit_params() runs Nelder–Mead, simulating via HybridAutomata, optimising the objective nchi_mean + 0.05 * rmse_mean.

5. Multi-island selection

Each island keeps its elite candidate, perturbs parameters locally, and ring-migrates best scores whenever gen % migrate_every == 0.

6. Feedback to the LLM

Comparison plots + metrics are optionally routed back through the vision LLM; without --use-vlm the script falls back to numeric jitter only.

Island Model

How the Island Strategy Expands the Search

evolve_islands() mirrors the multi-population layout of island.html. Each island re-evaluates the seed JSON, keeps the lowest nchi_mean candidate, and either jitters fitted parameters through the template extractor or asks the vision LLM for a structural edit. Ring migration appends the best automaton from island i to island (i + 1) every migrate_every generations, ensuring cross-pollination without overwriting local elites.

Distributed Loop

Per generation we execute:

for i, pop in enumerate(islands):
    elite = select_best(pop)
    new_pop = [elite]
    for j in range(1, pop_size):
        if use_vlm:
            img64 = image_to_base64(elite.plot_path)
            proposal = vlm_propose(client, model, img64, elite.json, elite.metrics)
        else:
            tpl, p0 = extract_param_template(elite.json)
            noise = normal(scale=0.1, size=len(p0))
            proposal = apply_params(tpl, p0 * (1 + noise))
        new_pop.append(evaluate_candidate(proposal))
    islands[i] = new_pop
if migrate_every divides gen:
    bests = [select_best(pop) for pop in islands]
    for i, elite in enumerate(bests):
        islands[(i + 1) % num_islands].append(elite)

Migration appends each island’s best automaton to its neighbour; elites remain in place to keep converged fits.

Operational Tips

Keeping the Loop Stable

Prompt Engineering

  • Ground prompts with stride, dt, and the fitted u(t) string so vlm_propose() maintains units.
  • Feed the previous best automaton back into the context block to steer the LLM toward incremental edits.

Parameter Fitting

  • Use --stride > 1 for exploration; drop to stride 1 for verification once nchi_mean stabilises.
  • Cap jitter amplitude if parameters collapse (default jitter scale is 0.1 inside the numeric branch).

Archive Hygiene

  • Persist elites under build/islands_run/<timestamp>; the script already writes best_automaton.json for reproducibility.
  • Ensure OPENROUTER_API_KEY and OPENROUTER_BASE_URL are set before toggling --use-vlm in automated runs.
