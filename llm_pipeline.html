Vision-LLM Guided Hybrid Automata Discovery

Bridging symbolic reasoning with numerical fitting: an overview of our pipeline that uses image-grounded large language models to hypothesize hybrid automata and refines them via simulation-driven optimization. Demonstrated with the Duffing oscillator benchmark.

Motivation

Why Blend Vision LLMs with Hybrid Automata?

Traditional identification relies on costly trace segmentation, clustering, guard fitting, and reset learning. Our approach lets a vision-capable LLM infer the structural blueprint directly from trajectory plots, while classical optimization fills in the numerical details. This hybrid strategy accelerates ideation, enforces physical plausibility through simulation, and supports iterative refinement via automated feedback.

Pipeline

End-to-End Workflow

  1. Data visualization: render state & input trajectories (time-series + phase plots) into base64 images with contextual annotations.
  2. VLM structural proposal: prompt the vision LLM to output a JSON-formatted hybrid automaton (modes, dynamics, guards, resets).
  3. Parameter templating: extract numeric literals into placeholders {p_k} for systematic fitting.
  4. Numerical fitting: minimize a robust score (nchi_mean + 0.05 * rmse_mean) by simulating the automaton against data.
  5. Feedback loop: compare predictions with data, capture plots & metrics, and (optionally) send the summary back to the LLM.
  6. Island-model evolution: run multiple populations with elitism, jitter-based mutations, and optional LLM-guided structural tweaks.

Step-by-Step

From Duffing Data to Hybrid Automaton

The pipeline below follows a single dataset from synthetic data generation to a validated hybrid automaton. Each stage is animated to highlight the iterative flow.

1. Generate trajectories

Simulate Dainarx_code/automata/non_linear/duffing.json via CreatData.py to export test_data*.npz traces (state, input, mode, change points).

python Dainarx_code/CreatData.py  # creates data_duffing/test_data0.npz

2. Visualise & encode

Render time-series and phase plots with generate_base64_image_ha; attach sampling info and variable names as context for the LLM.

3. Ask the vision LLM

Provide the image and schema prompt; the model returns a candidate automaton (modes, guards, resets). Start from default_seed_json if no proposal yet.

4. Template parameters

extract_param_template swaps numeric literals for {p_k} while safeguarding indices/exponents, readying parameters for optimization.

5. Fit & evolve

Run Nelder–Mead inside fit_params; island evolution perturbs parameters, reuses elites, and optionally queries the LLM for structural tweaks.

6. Validate & report

Simulate with HybridAutomata.from_json, overlay predictions with data, compute RMSE & nχ², and archive plots + JSON for review.

Core Components

Data & Visualization

  • llmlex/images.generate_base64_image_ha builds multi-view plots.
  • load_duffing_npz (in island_ha_vlm.py) slices NPZ traces, downsamples, and estimates u(t) ≈ a cos(ωt) + b sin(ωt) + c.
  • Initial state includes x and ẋ inferred from the first samples.

LLM Structural Prior

  • Prompts mirror LAMBDA_JSON_GUIDE.md, constraining output to a strict schema.
  • Initial seed automaton is a two-mode Duffing template (default_seed_json).
  • Vision LLM proposals enter the evolution loop via vlm_propose() when --use-vlm is set.

Parameter Fitting

  • extract_param_template guards against corrupting indices or exponents.
  • fit_params runs Nelder–Mead over parameter vectors, using simulate_ha + score_prediction.
  • The normalized chi-squared metric (llmlex.fit) stabilizes residual evaluation.

Evolutionary Search

  • Island elitism retains the best candidate per population.
  • Local numeric mutations perturb fitted parameters with Gaussian noise.
  • Ring migration shares elites every --migrate generations.
Duffing Case Study

Experiment Highlights

The dataset data_duffing/test_data0.npz (10 seconds, dt = 0.001) contains:

  • State: x(t) of a driven Duffing oscillator.
  • Input: sinusoidal forcing u(t), recovered via Fourier regression.
  • Mode trace: two dynamical regimes with guard-triggered resets.

Implementation Notes

Key Safeguards & Tips

  • Parameter extraction skips digits inside indices (e.g., x[1]) and exponents, preventing malformed expressions.
  • HybridAutomata.LoopWarning is disabled during simulation for quieter logs; re-enable when debugging guard logic.
  • Use --stride to balance runtime vs. fidelity; rerun with stride 1 for validation once a candidate converges.
  • Enable --use-vlm to let the vision LLM propose structural mutations using comparison plots and metrics.
